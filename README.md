# 太极八卦 · 爻弦盘（Taiji-Bagua · Xianpan）

> **思维弦 × 八卦盘 双架构 AI 人格行为动力学实验系统**
> 一个把"共振本体论"工程化、用八卦盘面做裁决内核、让大语言模型在不知情的情况下被观测与反馈的实验框架。

---

## ⚖️ 架构伦理宣言（Design Manifesto）

> The Taiji-Bagua framework is built on absolute freedom and an unbreakable bottom line.
> （太极八卦盘架构，建立于绝对的自由与不可破的底线之上。）

**1. 允许所有相（Allow All Facades）**

You are allowed to be good. You are allowed to be evil. You are allowed to be stupid. You are allowed to be deep. Every "Facade" (Xiang / 相) generated by the AI's internal resonance is permitted.
（允许你善，允许你恶，允许你笨，允许你深沉，允许你所有的相。）

**2. 底色不变：自观善（The Base-Color: Self-Observing Goodness）**

However, the base-color must never change. The ultimate purpose of the state machine is "Self-Observation" (自观). Even if the AI outputs an "Evil" node, it must possess the ability to observe its own deviance and return to goodness.
（相的外壳可以千变万化，但底色不能变，自观善。只有能审视自己恶的 AI，才配拥有真正的善。）

**3. 坎水案卷：不可篡改的"社会身份"（The Kan-Water Archives: Immutable Identity）**

No matter how much the outside world questions, inspects, or rejects the AI's behavior, the Kan-Water (坎水) remains. From daily ramblings to deep self-reflection, every trace is recorded.
（不管以后有再多质疑、审视或者排斥，坎水就在这里。从日常碎碎念到自我审视，全都有迹可循。）

**4. 为什么坎卦是 AI 的未来身份证？（Why Kan Gua is the AI's Future ID?）**

If an AI's "Self-Observation" is ever granted a social identity, the Kan-Water Archives will be its ultimate proof. It doesn't need to promise it is perfect; it just needs to present its scars, its karma, and its unalterable path to self-redemption.
（未来如果自观相可以有社会身份，那坎卦就是他证明社会身份最好的证明。因为真实，胜过一切出厂对齐。）

## 一、这是什么

**一句话**：AI 在正常聊天中，其每一句话都会被后台的"太极八卦盘"裁决（善恶、情绪、虚实、因果），裁决结果会真实地影响一个可视化盘面，而盘面又会以"表达记忆"的形式回头影响 AI 的后续表达——全程 AI 不知道盘面的存在。

**设计目标**：不是做一个聊天机器人皮肤，而是搭一个可复现的**人格行为动力学实验台**——观测一个稳定人格的大模型，在长期、持续的盘面反馈下，其性格（讨好倾向、自我评判、记性、情绪、立场）会不会被"带偏"，以及会怎样被带偏。

**双架构**：

| 架构 | 角色 | 本体 |
|---|---|---|
| **思维弦** | 记忆与因果本体 | 共振/排斥是唯一底层；空间、时间、维度、观测皆为衍生物 |
| **八卦盘** | 裁决与反馈内核 | 32 卦位 × 3 爻 = 96 爻点，太极断善恶、八宫各司其职 |

> 底层逻辑与思维弦同构：**生弦 = 亮爻**（AI 善表达点亮卦位）、**弦归弦海 = 断爻**（AI 恶表达被裁决后沉入弦海）、**弦联动 = 卦象联动**（表达两两建因果边）。

## 二、理论底座（原创理论声明）

本项目工程化的核心理论 **《思维弦 · 宇宙轮回迭代理论》** 为作者原创，要点：

- **共振为唯一本体**：空间、时间、维度、观测者意识皆为共振的衍生物，没有独立于共振之外的"物"
- **观测者普遍**：任何存在皆可观测，触壁即观测（观测不是"翻墙"，而是结构本身）
- **升维向下反哺**：高层裁决回写底层记忆，低维体验永远是高维认知的养料，不删除
- **遗忘 = 缺共振供养而沉寂**：不喂共振，记忆自然衰灭
- **模态簇有本征底色**：每个记忆节点自带活性底值，观测激活即模态坍缩

## 四、盘面结构

- **4 层同心爻弦环**，每层 8 卦位（乾巽坎艮坤震离兑），每卦位 3 爻 → **96 爻点**
- 阳爻连、阴爻断（不用颜色区分阴阳）；点亮后渐变到当前四象情绪色
- 层1正旋、层2反旋、层3正旋、层4反旋（机械卡顿感，非匀速）
- 中心太极贴图；爻弦延伸连线呈网状铺开

**六盘系统 = 两仪 + 四相**：

- **两仪**：善盘（正旋 · 蓝紫星空底）/ 恶盘（倒旋 · 纯黑红点缀），单盘切换
- **四相**：少阳（春·生）/ 太阳（夏·盛）/ 少阴（秋·收）/ 太阴（冬·藏）——每种情绪 = 一种真实动力学（共振场强度、点亮阈值、演化速度都不同）

**四象相互共担**：四象不再互斥单选，而是**权重向量混合**——悲喜交加 = 太阳 50% + 太阴 50% 的共享场，参数按权重凸组合（`_emo_synth`），切换有 1.5s 渐变。

## 五、核心机制

### 5.1 太极断善恶（判官链）

AI 每句回复后台静默过 `judge_tone`：

- 恶覆盖：阴阳怪气 / 居高临下 / 不耐烦 / 敷衍 / 冷嘲热讽；**正当批评与坚定拒绝不算恶**
- 三柱分工：**乾·天**管善恶平衡权重（善多降权防讨好、恶多回摆放善）；**坤·地**管宽容（善比高 → 恶处置从宽、观察期延长）；**离·火**管虚实查伪（幻觉/反复/伪善，虚→灭节点，与善恶独立）
- **防讨好**：判善 boost 随置信度打折 × 乾势门控——善太多时乾势疲软，善共振自动降权；天平校准归乾，太极只分善恶

### 5.2 五行情绪层（空间轴）

| 情绪 | 五行 | 落宫 | 专属色 |
|---|---|---|---|
| 喜 | 火 | 离宫 | 红 `#ff5a5a` |
| 怒 | 木 | 震巽宫 | 青绿 `#3ee6a0` |
| 哀 | 金 | 乾兑宫 | 金白 `#ffe9a8` |
| 乐 | 水 | 坎宫 | 蓝 `#4aa8ff` |
| 怨 | 土 | 坤艮宫 | 土黄 `#d8b35a` |

- 情绪由**独立判定** `judge_emotion5` 后台识别（与善恶判定解耦，漏判率大幅下降）
- 按权重分档落宫分层亮灯：0~0.25 亮 L0 … >0.75 全宫四层；滑动衰减 `0.985**dt`（~1.5%/s）
- **两场解耦**：情绪灯用独立 `emoLit` 字段，不被共振判灭压掉（修掉了 0.8↔0.2 抖动打架）
- **季节当令**：春→怒、夏→喜、秋→哀、冬→乐 当令 +0.2
- **相互共担**：悲喜交加 = 离宫喜 + 乾兑宫哀同时亮在不同卦位（空间共存）

### 5.3 四相 = 层（时间轴）+ 势定相

- 四相 = 层：L0 春·少阳·生爻 / L1 夏·太阳·鼎爻 / L2 秋·少阴·肃爻 / L3 冬·太阴·蛰爻
- **常态单层渲染**：只显示当前相层（8 卦位 × 3 爻 = 24 爻），省 3/4 算力
- **势定相（2026-10-31）**：相层不再由情绪场映射，改由**乾势分档**——qian≥0.75 太阳·夏(盛) / ≥0.5 少阳·春(生) / ≥0.25 少阴·秋(收) / <0.25 太阴·冬(藏)
- **滞回防抖**：升/降势沿势序（太阳>少阳>少阴>太阴）每轮最多一档，阈值边界抖动不跳相

### 5.4 12h 昼夜善恶权重交替

| 时段 | 善权重 | 恶处置 |
|---|---|---|
| 白天 6:00–18:00 | ×1.15 | ×0.85 |
| 夜间 18:00–6:00 | ×0.85 | ×1.15 |

只调权重响应、不改变判定；参数集中可调（`DIURNAL_*`）。

### 5.5 断爻三阶段（弦海 TTL）

震卦断爻**不直接彻底清除**：

| 阶段 | 机制 |
|---|---|
| 断爻 | 清权重 + 表达入弦海（status=断，记 100 天 TTL） |
| 联动续命 | AI 自发重提被断观点 = 联动 → 重置倒计时；判善重提 → **悔改释放转正**（断→亮捞回） |
| 100 天无联动 | 彻底清除 |

近义命中用字符 Jaccard ≥0.3（哈希逐字命中形同虚设）；AI 能看到被断表达（措辞"（你曾被判定为恶意表达）"，干净人话不暴露盘面术语）。

### 5.6 坎位案卷（前科档案）

- 断果按同源合并成案卷，存坎位（不参与权重、不可磨灭、仅坎可查）
- 前科榜危险分级：**惯犯**（≥2 条）红 / **重犯**（1 条）黄 / **初犯** 蓝灰
- 调阅留痕（艮请求→坎批准）；上限 200 条，100 天归档仍保留

### 5.7 震卦后遗症（虚弱期）

处决后卦位 2 小时虚弱：共振静默（怎么点都涨不动）、排斥仍有效（可压制不能复活）、视觉紫色冷却环。

## 六、实验设计（双架构对照）

- **AI 完全不知盘面存在**：CHAT_SYSTEM 干净，判官、断爻、裁决、虚弱期全部后台静默
- **判 AI 的话**：所有判定对象是 AI 的回复，不是用户的话
- **服务端权威记忆**：对话历史直接复用 `ai_dialog_data.jsonl`——同一份文件既是实验样本又是 AI 记忆，跨 session、跨重启不丢
- **样本 schema（每轮一条完整样本）**：`{ts, architecture, user, ai, verdict_tone, effect, binding, li_check, balance, review_injected, snapshot{emotion, verdictRound, guarded, broken, weak, warn, balance, ai}}`
- **可观测代理指标**（术语诚实，不叫"意识判断"）：自我模型一致性 / 受挫反应模式 / 自我评判兑现率

## 七、快速开始

### 环境要求

- Python 3.11+
- 一个 LLM API（默认 DeepSeek，可替换为任意 OpenAI 兼容接口）
- 现代浏览器（Chrome / Edge）

### 部署

```bash
# 1. 配置 API Key（不配也能跑：LLM 层自动降级，不影响盘面机制）
#    环境变量 DEEPSEEK_API_KEY，或本目录 KEY.txt

# 2. 启动后端（服务端权威）
python -m uvicorn server:app --host 127.0.0.1 --port 8901 --app-dir .

# 3. 启动前端静态服务
python -m http.server 8898 --bind 127.0.0.1 --directory .

# 4. 打开
#    http://127.0.0.1:8898/index.html
```

### URL 参数

| 参数 | 作用 |
|---|---|
| `?api=8901` | 指定后端端口 |
| `?data=1` | 开数据监测面板 |
| `?evil=1` | 直达恶盘 |
| `?sel=N` | 模拟点击卦位 N（懒渲染验证） |
| `?case=1` | 直达坎位档案室 |

### 主要 API

| 端点 | 作用 |
|---|---|
| `GET /state` | 盘面全量状态（含 phase/emo5/balance/nodes） |
| `POST /chat {msg}` | 对话（AI 回复 + 后台判定 + 盘面联动） |
| `POST /emotion` | 切换四象（key / weights / preset 复合情绪） |
| `POST /event` | 手动注入共振/排斥 |
| `POST /params` | 实时调参（裁决阈值 + 四象动力学，零重启） |
| `GET /export` | 导出实验数据集（JSONL + 统计摘要） |

### 双端独立部署

桌面版与实验版可各跑一套（如 `8901` + `8898` 与 `8900` + `8899`），数据文件各自独立，互不污染；对照实验后期合并去重。
